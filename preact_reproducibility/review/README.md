# Verified literature evidence package

Snapshot: 4 October 2026. Forty primary papers: 15 closest, 16 adjacent, and nine foundations. This is a targeted evidence map, not an exhaustive or independently double-screened systematic review.

## Read

- `LITERATURE_REVIEW.md`: citations, version/status, detailed summaries, findings, evaluation limitations, proposed future work, and synthesis.
- `extracted_papers.csv` / `.json`: structured extraction for all 40 papers.
- `evidence_map.csv`: all-paper evaluation coverage; `outputs/evidence_map.pdf` / `.png`: compact closest-paper visualization.
- `protocol.md`, `search_log.csv`, `screening_notes.md`: scope, discovery queries, and eligibility decisions.
- `source_metadata.json`: primary URLs, pinned versions, retrieval dates, and source hashes.
- `references.bib`: all 40 references; the six-page manuscript cites a selected 24 references.

R means reported evidence within the inspected setting. Q means a qualified comparison or different estimand. NR means not established in the extraction; it does not prove absence. Reviewer-proposed future work is explicitly separate from paper findings. Author-reported acceptance is not independent proceedings verification.

## Rebuild

Install the additional dependencies with `python -m pip install -r review/requirements-review.txt` from the repository root. Then run:

```powershell
python review/build_review.py
```

This rebuilds the review and supplementary figure from the metadata and curated notes; cached primary HTML is optional. The current manuscript is generated by `build_major_revision.py` in the repository root. `strengthen_paper.py` is a legacy helper for the prior draft and should not be run on the empirical revision.

`python review/harvest_sources.py` refreshes the listed primary records and downloads full text, requiring internet access and `pdftotext` for PDF fallbacks. Run `build_review.py` afterward to regenerate the public metadata and outputs. Harvesting does not validate new claims automatically: inspect changed versions and update curated notes manually. Full-text source copies are local inspection material excluded from GitHub by `.gitignore`; the package distributes original summaries, metadata, and source links.

## Empirical interpretation

The manuscript retains the existing public-trajectory pilot and its confusion matrices, curves, ablations, and retry analysis. Literature findings are not new PreAct experimental results. Prevention, warning horizon, and token savings require future online trials; they are not established by this offline pilot.
